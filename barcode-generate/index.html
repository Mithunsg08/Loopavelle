How to make a barcode or QR code online

Choose a type

Select QR Code or Barcode, then pick the format that matches your use, such as EAN-13 for retail or Code 128 for inventory.

Enter your data

Type a link, Wi-Fi details or a product number. The preview updates as you type and tells you if the value is invalid for that format.

Download and use

Save a PNG for screens and documents, or an SVG for crisp printing at any size. You can also copy the image or print it.

Private by design

Barcode Generate creates every code locally in your browser. Your URLs, Wi-Fi passwords and product numbers are never uploaded, stored or tracked.

Codes are static, so they never expire and have no scan limits. Test each printed code with a phone before you publish it.

Frequently asked questions

Is Barcode Generate free?

Yes. It is free, needs no account, and adds no watermark or scan limit.

Are my codes uploaded to a server?

No. Every barcode and QR code is created in your browser, so your data never leaves your device.

Which barcode format should I use?

Use EAN-13 or UPC-A for retail products, Code 128 for shipping and inventory, Code 39 for IDs and labels, and ITF-14 for cartons.

Do the QR codes expire?

No. These are static QR codes. The data is stored in the image itself, so they work forever.

PNG or SVG?

Use SVG for print and large formats because it stays sharp at any size. Use PNG for web, documents and apps.

What does error correction mean in a QR code?

Higher levels (Q, H) let a QR code scan even if part of it is damaged or covered, but make the pattern denser.
