    What makes a password strong?

    Length first

    Every added character multiplies the guesses an attacker needs. A random 16-character password is far harder to crack than a short one with clever substitutions.

    True randomness

    Humans pick patterns. This tool draws every character from your browser's secure random generator and avoids modulo bias, so each character is equally likely.

    One password per account

    Reusing passwords lets one data breach unlock your other accounts. Generate a new one for each site and keep them in a password manager.

    How to use the password generator

    Pick a type: Random for maximum strength, Passphrase for something you can type from memory, or PIN for numeric codes. Set the length, choose the character types, and copy the result. The meter shows entropy in bits and an estimate of how long an offline attack would take at one trillion guesses per second.

    For important accounts such as email, banking and your password manager, aim for 80 bits of entropy or more and turn on two-factor authentication.

    Frequently asked questions

    Is this password generator safe to use?

    Yes. Passwords are created locally in your browser using the Web Crypto API. They are never sent to a server, logged or stored. You can disconnect from the internet after the page loads and it still works.

    How long should a strong password be?

    Use at least 16 characters for important accounts. Length adds more security than complexity: every extra character multiplies the number of possible passwords.

    What is password entropy?

    Entropy, measured in bits, describes how unpredictable a password is. Each extra bit doubles the guesses an attacker needs. 80 bits or more is considered very strong.

    Passphrase or random password: which is better?

    Random passwords are best for password managers. Passphrases of five or more random words are easier to type and remember, and still very strong.
